# Task ID: 6
# Title: Create Time Entry Form Component
# Status: pending
# Dependencies: 2, 3, 4
# Priority: high
# Description: Develop a mobile-first form component for creating and editing time entries with all required fields and validation.
# Details:
Create a React component for time entry form with the following features:

1. Form fields:
   - Date (date picker, defaulting to current date)
   - Time Input Method toggle (Start/End Time vs Duration)
   - Start/End Time pickers (conditional)
   - Duration input (hours/minutes, conditional)
   - Rate dropdown (showing applicable rates by effective date)
   - Client dropdown (optional, filtered by user access)
   - Project dropdown (optional, filtered by selected client)
   - Product dropdown (optional)
   - Department dropdown (optional)
   - Description textarea (required)
   - Private Notes textarea (optional)
   - Tags selection (optional, multiple)

2. Functionality:
   - Auto-calculate duration when using start/end time
   - Pre-fill last used values for frequent combinations
   - Form validation
   - Submit handling
   - Cancel/Reset options

Use Shadcn UI components for consistent look and feel. Implement responsive design for mobile-first experience.

# Test Strategy:
1. Unit tests for form validation
2. Test auto-calculation of duration
3. Test form submission with valid and invalid data
4. Test responsive design on various screen sizes
5. Verify dropdown filtering works correctly
6. Test with keyboard navigation and screen readers for accessibility
